# 名词卡

讲稿里会出现的英文词，一句话解释。上台前扫一遍就行。

| 英文 | 中文 | 一句话 |
| --- | --- | --- |
| frequency | 频率 | 电网的误差信号。50 Hz 是目标值，偏离就说明供需不平衡 |
| inertia | 惯量 | 旋转机组自带的缓冲能力，让频率掉得慢一点。单位 MW·s |
| RoCoF | 频率变化率 | rate of change of frequency，频率掉多快。Hz/s |
| contingency | 突发事件 | 电网突然丢掉一台大机组或一条联络线 |
| frequency response | 频率响应 | 检测到频率偏差后出力把它拉回来的服务 |
| FFR | 快速频率响应 | fast frequency response，上面那件事的"快速版"，百毫秒量级 |
| FCAS | 频率控制辅助服务 | 澳洲电网给频率响应付钱的那个市场 |
| droop | 下垂 | 频率掉多少、出力加多少的比例关系。等效于比例控制 |
| deadband | 死区 | 偏差小于这个值就不动作，避免反复微调 |
| load shedding | 甩负荷 | 频率实在拉不回来，主动切掉一部分用户。最后手段 |
| UFLS | 低频减载 | under-frequency load shedding，自动执行甩负荷的保护装置 |
| state of charge (SoC) | 荷电状态 | 电池还剩多少电，百分比 |
| energy density | 能量密度 | 每公斤能储多少能量，Wh/kg |
| power density | 功率密度 | 每公斤能出多少功率，W/kg |
| supercapacitor / ultracapacitor | 超级电容 | 两个词同义。小桶粗龙头的那一个 |
| grid-forming | 构网型 | 变流器不只是跟着电网走，而是主动建立电压和频率 |
| ancillary services | 辅助服务 | 电网为了维持稳定而采购的各种服务，频率响应是其中之一 |

## 两个容易说错的

**MW 和 MW·s**
- MW 是功率（龙头多大）
- MW·s 是惯量的单位（缓冲有多少）
- 讲到 Hornsdale 能提供 "2,000 MW·s 的惯量" 时，**不要读成 2,000 MW**，差着量纲。

**超级电容不是电池**
它靠静电储能，不发生化学反应，所以能充放上百万次而几乎不衰减——但也正因为不发生化学反应，存不了多少能量。
