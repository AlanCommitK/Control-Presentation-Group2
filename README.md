UESTCHN4002，2026 年 11 月 25 日（周三）课上的 5 分钟小组展示。当天随机抽两人：一人讲第 1–6 页（前半场），一人讲第 7–14 页（后半场），两半都要准备。

## 怎么打开

1. 在仓库首页点绿色的 **Code** 按钮，选 **Download ZIP**。
2. 解压后双击 `index.html`，用 Chrome、Edge 或 Safari 打开。不需要联网。

只要单个文件时，在 GitHub 上点开那个文件，再点右上角的下载按钮（Download raw file）。

## 先看这个

`index.html` 是准备材料总页：讲什么、怎么放映、14 页逐页讲解、读音表、15 道预备问答。下面这些文件也都嵌在它的「下载」区里，只拿到这一个文件也够用。
