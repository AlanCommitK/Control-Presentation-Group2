## 为什么选这个题

题面要 *"a real-world Control Engineering application"*，关注 *"technical principles, challenges, and practical relevance"*。

这个题三样都占满：

- **技术原理**：反馈控制最本质的那条——误差 → 动作 → 误差变小。电网频率就是误差信号。
- **挑战**：真实、可量化、而且反直觉——瓶颈不是储了多少电，是**多快能出力**。
- **现实相关**：有一座真机（南澳 Hornsdale），有公开的第三方评估报告，有真金白银的数字。

而且它不要求听众懂拉普拉斯变换、根轨迹或者波特图。**整场讲完不写一个公式。**
